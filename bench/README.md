# ベンチマーク

`@teppen/react-ui` の複数のバージョンを、実際のブラウザ（Chromium）で同じ操作をして比べます。変更でテーブルが遅くなっていないかを確かめるためのものです。

## 使い方

```sh
# リポジトリの直下で、今のコードをビルドする（"local" を比べるとき）
npm run rollup

cd bench
npm install
npx playwright install chromium   # 初回のみ
npm run bench -- 1.8.15 2.12.0 local
```

- 引数に、公開済みのバージョン（`npm pack` で取得）か `local`（`../dist` のビルド）を並べます。
- 結果は、そのまま PR などに貼れる Markdown の表で表示されます。
- 環境変数
  - `REPEAT`：1つの操作を測る回数（既定 5）。中央値を表示します。
  - `ONLY`：名前にこの文字を含む操作だけ測ります（例：`ONLY="Update"`）。
  - `PLAYWRIGHT`：別の場所にある Playwright を使うときのパス。

## 測り方

- どのバージョンにも同じアプリ（`app.jsx`）を使います。7列（文字列・数値・選択肢、うち4列は編集可）、チェックボックスありです。
- React 18.3.1 で動かし、Tailwind CSS はバージョンごとに、そのバージョンのファイルから生成します。CSS が変わったことによるレイアウトの差も測れます。
- 時間は、操作した瞬間から、次の画面が描かれるまでです。ページの中で測っています。1回ごとにページを読み込み直します。
- アプリは行を state に持ち、セルの編集を保存するたびに行を更新します。社内アプリと同じ使い方です。`cols` はコンポーネントの中で毎回作ります（よくある書き方）。`useMemo` で固定した場合も1項目だけ測ります。
- 1フレームは約 16ms なので、16ms 前後の値は「次の描画までに終わった」という意味です。

## 結果の例（2.12.1 の変更時）

| 操作 | 1.8.15 | 2.12.0 | 2.12.1 |
|---|---:|---:|---:|
| 初回表示、1万行（50件/ページ） | 65 | 78 | 74 |
| 初回表示、1,000行（全件表示） | 443 | 414 | 404 |
| 並べ替え、1万行（50件/ページ） | 41 | 34 | 34 |
| 並べ替え、1,000行（全件表示） | 381 | 427 | 438 |
| 1行の更新、1,000行（全件表示） | 106 | 119 | 32 |
| セルを編集して保存、1,000行（全件表示） | 107 | 115 | 36 |
