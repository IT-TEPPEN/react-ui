# 機能案（ロードマップ）

今後追加を検討する機能の一覧です。実装したものは「対応済み」に移します。
優先度は、業務画面でセルを編集・貼り付けして使う前提での目安です。

## 検討中

| 機能 | 内容 | 規模 | 備考 |
|---|---|---|---|
| 編集や貼り付けの取り消し（Ctrl+Z） | 直前の編集・貼り付けを元に戻す | 中 | 保留。編集のたびに保存する画面では「元の値で保存し直す」ことになり、行の削除などテーブル外の変更も絡むため、戻す処理はアプリ側に置く。要望が出たら、テーブルは貼り付けのまとまりと Ctrl+Z の通知だけ手伝う |
| 複数の列を組み合わせた並べ替え | 「部署 → 年齢」のように並べる | 中 | 要望があれば |
| AND と OR を混ぜた条件 | 「A かつ (B または C)」のような条件 | 大 | 同じ列の「または」は `in` で表せる |
| サーバー側での並べ替え・絞り込み | 数万件以上を扱う場合に、ページごとに取得する | 大 | 要望があれば |

## 次のメジャーバージョン（3.0.0）の候補

- `package.json` に `exports` を追加する（`dist` 内のファイルを直接 import している利用者に影響）
- 綴り誤りの `initialCondition.pagenation` を削除する（2.1.0 から `pagination` を推奨）

## 対応済み

- 2.13.0（予定）：範囲を選んで Delete / Backspace でまとめて空にする、Ctrl+D で下へコピー（どちらも `onUpdateRow` で反映）
- 2.12.1：`cols` をコンポーネント内で毎回作っても、1行の更新で全行を描き直さない（1,000行表示で約 110ms → 約 35ms）。`render` を新しい関数に変えたときに表示が更新されない不具合の修正。比較用のベンチマーク（`bench/`）
- 2.12.0：ヘッダーのチェックボックスで選ぶ範囲（`checkbox.selectAll`：全行 / 絞り込み後の行 / 表示中のページ）
- 2.11.0：列の表示・非表示（`columnSelector`、`disableHide`、`hiddenColumns` の保存・復元）
- 2.10.0：列の固定（`pinned: true` の左端の列を、横スクロールしても表示したまま）
- 2.9.0：Tab / Shift+Tab で左右へ、Enter / Shift+Enter で上下へ移動。編集中は確定してから移動
- 2.8.0：1ページあたりの件数を利用者が切り替える部品（`rowCountPerPageOptions`）
- 2.7.0：`sortValue` / `filterValue`（並べ替え・検索に使う値を列ごとに指定）、ページと列幅を `onConditionChange` / `initialCondition` で保存・復元
- 2.6.0：文言の見直し（ja / en）、`loading` / `noDataMessage`、CSS 変数によるデザインの変更
- 2.5.0：`render` の列を、`disableSort: false` / `disableFilter: false` で並べ替え・絞り込みの対象にする
- 2.4.0：全列のキーワード検索、`in` / `not in`、AND / OR の切り替え、`initialCondition.filters`、`onConditionChange`
- 2.3.0：日本語の順での並べ替え、部分一致で表記の違いを無視、選択式の列をラベル順に並べる
- 2.2.0：選択中のセルで日本語入力から編集を始める、`locale`（ja / en）
